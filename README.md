# Project Cellule

## Overview

Project Cellule is a project in the design phase that explores the use of artificial intelligence to analyze and synthesize different categories of health data.

## Objective

To investigate how combining health information could help explore personalized care options and support analysis by qualified professionals.

## Development Stage

The project is currently at the conceptual stage.
Initial work may use synthetic data, without personal data or records from real patients.

## Design Principles

- Privacy protection
- Evaluation of limitations and performance
- Appropriate human oversight
- Verification of regulatory requirements before any clinical use

## Status

This project is not presented as a validated medical device.
No claims regarding clinical performance are made at this stage.
